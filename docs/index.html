[01] DECENTRALIZED MESH TOPOLOGY

全域分散式節點網格架構

從社群節點發布、Cloudflare KV 心跳註冊，到前端動態發現與直連通話的端到端資料流。

sequenceDiagram
    autonumber
    participant Client as ai-brain-site (瀏覽器)
    participant KV as Cloudflare KV (註冊中心)
    participant Tunnel as Cloudflare Quick Tunnel
    participant Node as glitch-voice-server (本機/社群節點)

    Note over Node: 1. 節點開機 (RTX 4060 / 8000 Port 順延)
    Node->>Tunnel: 建立本機 HTTPS 穿透通道
    Tunnel-->>Node: 回傳公網 URL (https://xxxx.trycloudflare.com)

    loop 每 60 秒心跳 (Heartbeat)
        Node->>KV: POST /voice/register (註冊 URL, 帶 TTL 300s)
        KV-->>Node: 200 OK (節點維持在線)
    end

    Note over Client: 2. 使用者開啟格莉奇OS
    Client->>KV: GET /voice/nodes (抓取所有在線社群節點)
    KV-->>Client: 回傳可用節點清單 [林亞澤 4060, 社群節點...]

    Note over Client: 3. 全雙工即時通話
    Client->>Tunnel: POST /api/glitch-call (包含訊息與歷史對話)
    Tunnel->>Node: 內網直連轉發至 FastAPI (Port 8000)
    Node->>Node: LLM 產生回應 + 台灣化雙軌音準 + TTS 聲學合成
    Node-->>Tunnel: 回傳 Base64 音訊 + 表情標籤 + 字幕
    Tunnel-->>Client: 即時播放語音並觸發立繪表情
無需許可 (Permissionless) 自建節點
任何開源社群成員只需 clone 本專案並執行 python server.py，其電腦即自動成為全域網路中的算力節點，無需經任何人審批即可為全網提供語音與推理服務。
⏱ TTL 自動過期與健康保證
每個節點以 60 秒為週期發送心跳維持在線。當節點電腦關機或斷線超過 300 秒，Cloudflare KV 將自動將其移除，確保前端使用者永遠只會連線到活躍節點。

開機主動顯存預熱 (Warmup)
伺服器啟動時主動對 GPU 顯存與 CUDA JIT 進行單次空推論，徹底消除首次通話時的冷啟動延遲，使第一句對話就能達到 1.2s 極速。
智慧 Port 自動順延 (Auto Probing)
開機自動探測 Port 8000 是否被佔用，若衝突則自動遞增（8001 → 8002...），Tunnel 與後台 UI 自動同步綁定，永不崩潰。
[03] DUAL-ENGINE BENCHMARKS

雙核心 TTS 聲學推論架構

結合 Diffusion Transformer 與 Flow Matching 的雙引擎熱切換體系。

引擎名稱 架構規格 總參數量 推論延遲 (RTF) 顯存佔用 核心優勢與適用場景
F5-TTS v1 Base (預設) 22-Layer DiT (Dim=1024) + Vocos 337 M (0.34B) ~0.9s (RTF=0.20) ~1.0 GB 極速超低延遲、高吞吐，專為即時電話對話設計
CosyVoice 3 (原生) Qwen2 0.5B LLM + Matcha Flow + HifiGAN 500 M (0.50B) ~3.4s (RTF=0.78) ~4.8 GB 正典細膩少女聲線、微弱呼吸感、支援情感 Prompt 指令
[04] ACOUSTIC NORMALIZATION

雙軌台灣化與《讀音替身表》

解決大陸聲學模型在台灣國語破音字、聲調與專有名詞上的發音偏差。

🇹🇼 兩岸詞彙轉換 (`LEXICON_SUBS`)
自動將大陸用語在地化為台灣慣用語：
• 視頻 → 影片
• 服務器 → 伺服器
• 代碼 → 程式碼
• 默認 → 預設
聲學發音音準拐杖 (`PRONUNCIATION_SUBS`)
修正大陸聲學模型的破音字與聲調缺陷：
• 林亞澤 → 林雅澤（鎖定台灣輕柔三聲 yǎ zé）
• 七行 → 七航（修正破音字 háng）
• 零失誤 → 靈失誤
• 垃圾 → 勒瑟
[05] QUICKSTART & DEPLOYMENT

成為社群節點：1 分鐘極速部署

只需 2 行指令，立即將你的 GPU 接入格莉奇分散式語音網絡。

# 1. Clone 儲存庫
git clone https://github.com/yazelin/glitch-voice-server.git
cd glitch-voice-server

# 2. 啟動伺服器 (自動建立 Tunnel 並註冊到 Cloudflare KV)
~/voice-venv/bin/python server.py

# 3. 打開瀏覽器控制台
http://127.0.0.1:8000

啟動後，瀏覽器打開 http://127.0.0.1:8000 即可查看專業錄音室廣播控制台，並一鍵啟動 ai-brain-site 前端！
